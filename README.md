# FRIENDS — Human Connection & Meaningful Social Discovery

> *"Find your people. Find your place. Build your world."*

A modern, intentional web application ecosystem for deep friendships and romantic relationships. Built with a **Golden × Obsidian** design system, holistic compatibility matching, privacy data governance, and real-world safety plans.

---

## ✨ Core Pillars & Architecture

### 1. FRIENDS SOCIAL
- **Holistic Compatibility Model (HCM)**: Multi-dimensional compatibility based on core values, conflict styles, affection languages, and conversation rhythms—zero superficial swiping.
- **Most Active Chat Window**: Public diurnal schedule indicator showing when each user is historically active on the app to chat (with live peak hour beacon and reply odds).
- **My World Profile**: 8-chapter autobiographical profile (Story, Career, Education, Lifestyle, Prompts, Media Museum, Preferences, and Privacy Controls).
- **Communication Sanctuary**: Mutual connection request gates, encrypted audio lounges, and zero-judgment AI conversation practice sandbox.
- **Micro-Social Circles**: Intimate groups capped at 5–10 members with live voice rooms and low-stakes reflection prompts.

### 2. FRIENDS EXPERIENCES
- **FRIENDS Events**: Public gatherings, synchronized watch parties, and private parties with automated address-hiding security until RSVP confirmation.
- **Social Growth Ladder**: 30-day interactive confidence progression, Friendship Academy micro-lessons, and sealed future letters.
- **Self Discovery**: Multi-stage psychographic quizzes with sharable identity cards.
- **Viral Share Engine**: 9:16 Instagram Story card designer, Friendship Wishlist manifestos, and "How Well Do You Know Me?" quiz cards.

### 3. FRIENDS CONNECT & TRUST
- **Universal Identity Hub**: 50+ service directory across 6 capability tiers with 3-tier sync level cycler (*Connected*, *Imported*, *Synchronized*).
- **Beyond FRIENDS**: External community discovery assistant (Discord, Reddit, Tandem, 7 Cups, etc.) for niche subcultures.
- **FRIENDS REAL & MEET**: In-app photo liveness check simulation, anti-catfish badges, and in-person meetup safety plans with automated check-ins.
- **Privacy & Data Governance Centre**: Granular per-field provenance, consent toggles, data retention rules, and instant DSAR JSON archive export (compliant with Sri Lanka PDPA No. 9 of 2022 & GDPR).
- **24/7 Crisis Support**: 1-click immediate triage and verified hotline directory (**1926 NIMH**, **1333 CCCline**, **Sumithrayo**, **1990 Ambulance**, **119 Police**).

### 4. GOVERNANCE & ADMIN OPS
- **Administrative Workspace (`/admin`)**: Telemetry metrics (WMCAU, D7 retention, verified ratio), live human verification queue, and zero-tolerance safety triage.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/thamaracode/Friends_Dating.git

# Navigate to frontend
cd Friends_Dating/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the platform.

### Production Build

```bash
cd frontend
npm run build
```
